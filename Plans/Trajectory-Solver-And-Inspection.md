## Work and review checkpoints

### 1. Constant-wind solver and old-vector characterization — complete

Implement SI input validation first. Positive finite mass, diameter, length, BC, velocity, twist, zero range, sample range, and step are required; temperature must be positive Kelvin, humidity in `[0,1]`, and pressure may be 0 for pressure derived from altitude. Reject a zero range beyond reachable flight, nonfinite calculations, or a request whose time/range cap is reached before a requested row. Do not silently omit rows. Support G1 and G7; port both complete drag tables, not a smooth substitute.

Port the atmospheric formulas and the bullet/solver path. The reference's core behavior is: air-relative velocity (`bullet velocity - wind`); drag indexed by Mach using local speed of sound; density-scaled G1/G7 retardation; gravity; corrected Miller stability fixed at launch; right-hand spin drift proportional to `t^1.83`; crosswind aerodynamic jump on *changes* in crosswind; RK2 midpoint integration at `dt = 0.001 s`; distance interpolation; and a zero search that adjusts pitch and yaw until target-plane error is below `1e-5 m` or it retains the best iterate on stall. If the best iterate misses that tolerance, return its trajectory and the signed vertical/lateral target-plane deviations plus their combined miss distance; mark the zero as approximate. Preserve `x/right`, `y/up`, `z/-downrange` signs. Use `maxIterations = 50`, `maxTime = 15 s`, simulate to `maxRange × 1.05`, and sample every load's authored `stepM` through its `maxRangeM` for the reference matrix. The .22 LR ends at 500 m; do not push it to 2000 m.

The solver API must take an explicit `zeroMode`: `.legacyWindAware` for the old matrix and `.calmAir` for the player screen. The latter finds the launch state with zero wind, then applies constant wind to flight without solving away the wind. `sightHeightM` is a separate argument: 0 for the matrix; 0.0508 m for the player default. Return range, drop, windage, velocity, flight time, and kinetic energy for each row. Raw physics returns SI values without formatting.

**Check:** The test target reads its bundled fixed files and recomputes all 36 cases / 660 rows. Compare range, drop, windage, velocity, and time individually using relative difference `abs(actual - expected) / max(abs(actual), abs(expected), 1e-12)` with a `1e-4` ceiling, except that drop and windage at the 100 m zero-range row use a `5e-8 m` absolute-difference ceiling. No other row or field gets an absolute-tolerance exception. Leave fixtures unchanged. Log case, range, field, expected, actual, and both worst absolute and worst relative differences, so the zero-row exception remains visible. Also check hand-worked signs: calm windage includes small spin drift; +x crosswind pushes right; changing air density changes retained velocity. Run the macOS Xcode build and tests successfully before closing this checkpoint.
